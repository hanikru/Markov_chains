# Markov_chains

Этот проект реализует моделирование цепей Маркова с использованием Python. Включает генерацию случайных цепей, моделирование траекторий и анализ вероятностей.

## Описание проекта

Проект предоставляет инструменты для работы с марковскими цепями:
- Генерация случайных матриц переходов
- Моделирование траекторий Markov chains
- Анализ вероятностей и стационарных распределений
- Вычисление вероятности траектории

## Использование

```python
from src.MarkovC import Markov_chains

# Создание экземпляра марковской цепи
mc = Markov_chains(3)  # Создает цепь с 3 состояниями

# Генерация случайной матрицы перехода
mc.random_matrix()

# Моделирование траектории
trajectory = mc.Mt(10)  # Траектория из 10 шагов

# Вычисление вероятности траектории
prob = mc.Pt(trajectory)
```

## Подробное описание методов

### Markov_chains класс

Класс реализует основные функции марковской цепи:

**Инициализация:**
```python
Markov_chains(size)
```
Создает марковскую цепь с заданным количеством состояний.

**Методы:**

1. `random_matrix()` - генерирует случайную матрицу перехода, где каждая строка суммируется до 1
2. `Rand_poz(idx)` - выбирает следующее состояние по вероятности из текущего состояния idx
3. `Mt(step)` - генерирует траекторию длиной step с начальным состоянием 1
4. `Final_distribution()` - вычисляет стационарное распределение цепи
5. `Pt(tra)` - вычисляет вероятность заданной траектории

## Примеры использования

```python
# Создание цепи с 4 состояниями
mc = Markov_chains(4)

# Генерация матрицы перехода
mc.random_matrix()

# Получение стационарного распределения
final_dist = mc.Final_distribution()
print("Стационарное распределение:", final_dist)

# Моделирование траектории длиной 20 шагов
trajectory = mc.Mt(20)
print("Траектория:", trajectory)

# Вычисление вероятности траектории
prob = mc.Pt(trajectory)
print("Вероятность траектории:", prob)
```

## Ограничения и особенности

1. Все состояния марковской цепи нумеруются от 1 до size (включительно)
2. Матрица перехода должна быть квадратной размером size × size
3. Строки матрицы должны суммироваться до 1 для корректного моделирования
4. Все вероятности должны быть неотрицательными
